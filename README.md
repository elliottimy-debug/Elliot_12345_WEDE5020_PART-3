Project Overview
Paws & Claws Sanctuary is a non-profit animal rescue organisation dedicated to saving abandoned domestic pets, providing medical rehabilitation, and placing animals into permanent, loving homes.
This web application serves as a comprehensive digital portal that allows users to:
•	Learn about the shelter's mission, values, and story.
•	Explore available animals through an interactive, searchable pet catalog.
•	Submit formal adoption and volunteer enquiries.
•	Contact the shelter for support or make financial contributions.



Organisation Background & Purpose
•	Organisation Name: Paws & Claws Sanctuary (Non-Profit Organisation)
•	Sector: Animal Welfare & Rescue Operations
•	Purpose: To address domestic animal neglect across South Africa by providing emergency shelter, veterinary care, community education, and ethical pet adoption.



Goals and Objectives
1.	Digital Reach: Establish an accessible web presence for potential adopters across desktop and mobile devices.
2.	Streamlined Adoptions: Simplify the adoption enquiry process through clear interactive web forms and validation.
3.	Interactive Search: Enable prospective pet owners to dynamically filter animals by species and age.
4.	Community Support: Facilitate volunteer applications and fundraising enquiries.



Target Audience
•	Prospective Pet Adopters: Families and individuals seeking to adopt vaccinated and microchipped pets.
•	Animal Fosters & Volunteers: Community members looking to offer short-term foster care or shelter assistance.
•	Donors & Sponsors: Supporters interested in funding veterinary supplies and animal welfare initiatives.



Proposed Features & Functionality
•	Semantic HTML5 Layout: Structured headers, navigation bars, main content areas, and footers across all 6 pages.
•	Interactive Pet Filtering: Filter catalog cards by category (Dogs, Cats, Seniors, All Pets) without page reloads.
•	Form Validation: Dynamic JavaScript validation on enquiry.html and contact.html with real-time feedback.
•	SEO Suite: Page-specific meta tags, search engine indexing directives via robots.txt, and structured XML sitemap (sitemap.xml).
•	Fully Responsive Design: Custom CSS media queries for desktop, tablet, and mobile views.



Technical Requirements
•	Languages: HTML5, CSS3, JavaScript (ES6+).
•	Hosting Platform: GitHub Pages / Netlify (Free Tier Static Web Hosting).
•	Version Control: Git & GitHub for repository hosting and commit history tracking.
•	Code Editor: Visual Studio Code.
•	Standards Compliance: W3C HTML5 & CSS3 compliance.

Wireframes & Visual Planning
Desktop & Mobile Wireframe Layout Concept
•	Header: Sticky navigation bar featuring logo on the left and navigation links on the right.
•	Hero Section: High-impact call-to-action banner promoting pet adoptions.
•	Grid Layout: CSS Flexbox & CSS Grid containers displaying 3 to 4 pet cards per row on desktop, collapsing to 1 column on mobile screens.
•	Footer: Site copyright, social links, and links to sitemap.xml and robots.txt.




Technologies Used
•	HTML5: Semantic structural tags (<header>, <nav>, <main>, <section>, <article>, <footer>).
•	CSS3: Flexbox, CSS Grid, custom variables, hover transitions, and responsive @media breakpoints.
•	JavaScript (Vanilla ES6): Event listeners, DOM manipulation, conditional form verification.




SEO & Search Optimisation Implementation
1.	Page Title Tag: Descriptive <title> elements on all 6 HTML files.
2.	Meta Descriptions & Keywords: Unique <meta name="description"> tags tailored for each page.
3.	Image SEO: All <img> tags include descriptive alt text for screen reader accessibility and image indexing.
4.	Search Directives: Includes a configured robots.txt file and an XML-compliant sitemap.xml file.
